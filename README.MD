# Droedex/FF — Feature First Engine (Experimental)

⚠️ **Warning**
This package is **experimental** and must **not be used in production**.
The API, architecture, and implementation are unstable and may change at any time without backward compatibility.

---

## About

`droedex/ff` (Feature First Engine) is an experimental Laravel package that explores a **feature-first architecture** approach.
Instead of organizing code around layers (controllers, services, repositories), this package encourages structuring your application around **features**.

This package is currently a sandbox for experimenting with patterns and ideas. It is **not a stable release**.

---

## Installation

> **Important:** Do not install this package in production. It is only for experimentation and research.

If you still want to try it:

```bash
composer require droedex/ff
